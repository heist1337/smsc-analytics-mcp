# Передача коллегам

Передать ссылку на репозиторий. Коллега клонирует его, устанавливает uv,
копирует `.env.example` в `.env` и записывает свой `SMSC_API_TOKEN`.
На Windows: `Copy-Item .env.example .env`.

В `mcp.example.json` заменить пути к checkout и приватному env-файлу. Клиент
запускает stdio-сервер сам. Проверка без аккаунта и сети:

```bash
uv sync --locked
uv run python -m unittest discover -b -s tests
```

Начать с `smsc_read(operation="catalog")`. Для живой проверки достаточно чтения
баланса; отправок SMS и платных проверок в сервере нет.

Другой аккаунт использует свою приватную SQLite-базу. Одновременные потребители
одного аккаунта должны координировать лимиты; отдельные базы не дают общий budget.
Не передавать свою SQLite-базу как демонстрационные данные: она содержит финансовую
историю, состояние загрузки и ключ обезличивания.

Для переноса своей установки остановить процессы и сохранить SQLite и env-файл
по защищённому каналу. При работающем процессе использовать SQLite backup API.
Сохранять checkpoints, HMAC и общий budget. Пустой кеш не является нулевыми расходами.
